# OpenAtlas
Open-source Minecraft world map mod

Features:
- In world and map configurable waypoints
- Export map to image file
- Cave mode
- Nearby locator bar visible players are visible on the map
- Death waypoints
- Group waypoint filtering

Usage:
- M to open map
- B to make a new waypoint
- U to open waypoint list

Map data is stored in `.minecraft/openatlas`
